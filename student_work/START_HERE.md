# Your Own Solutions — Start Here

This folder is intentionally kept separate from the provided reference implementations. **Your first task** is to solve one exercise by hand and implement it here yourself. Do not just copy the reference algorithm into another file.

Suggested first contributions:

1. Write `my_bisection.py` that outputs a three-iteration table for a new function. Explain why the bracket changes after each row.
2. Write `my_newton.py` that calculates and checks two Newton updates; note why the derivative of a constant is zero.
3. Add `test_my_methods.py` with at least one correct-result and one failure-case test for your chosen method.
4. Record what you learned in `progress/REVISION_LOG.md` and commit your changes.

The provided tests cover the reference implementations in `src/`; writing new code and tests here is how you demonstrate **your own** progress.
