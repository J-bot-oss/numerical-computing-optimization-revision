# Contributing to your revision lab

1. Read the relevant week note and attempt the question on paper.
2. Explain the calculation in your own words in your revision log.
3. Make a small code or documentation improvement.
4. Add or update a test; run `python -m pytest -q`.
5. Commit the change with a descriptive message.

If collaborating, use pull requests and keep source attribution clear. Avoid uploading private assessment records.
